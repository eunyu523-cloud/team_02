# 🏢 Team02 - 서울 지역 아파트 실거래가 및 자산 트렌드 분석

## 📌 프로젝트 소개
- **주제:** 국토교통부 공공데이터 API를 활용한 서울 주요 자치구 아파트 실거래가 트렌드 분석
- **목적:** 실제 부동산 거래 데이터를 수집하여, 자치구별 매매 가격 추이와 격차를 데이터 기반으로 시각화하고 인사이트를 도출합니다.

## 🚀 실행 방법 (How to Run)
1. 필수 라이브러리 설치
   ```bash
   pip install -r requirements.txt
   ```
2. Streamlit 앱 실행
   ```bash
   streamlit run app.py
   ```
